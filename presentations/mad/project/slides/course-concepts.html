[50 s] The course policy lists seven units. I will be exact about what the app uses. Unit 1, platform: an Android Studio project, run on the emulator and on a phone. Unit 2, UI components under CO1: buttons, Material filter chips as the choice controls, a navigation drawer as the menu, three alert dialogs for create folder, move and delete, multiple screens through six drawer destinations plus a second activity, and Canvas graphics and sliders in the Pipeline Lab. I do not use a date picker, a spinner or toasts. Unit 3, images and files under CO2: camera and gallery images, FileProvider, and JSON text plus JPEG files in private storage. Unit 4, location, is not used: the app is offline and has no reason to know where the user is. Unit 5, Flutter, is not used because native Kotlin gives direct access to OpenCV, ONNX Runtime and TensorFlow Lite. Unit 6, databases under CO3, is not used: documents are stored as files and Firebase needs a network; a Room database is my future scope. Unit 7: there is no server by design, a release build with R8 is verified, but the app is not published on Google Play.
