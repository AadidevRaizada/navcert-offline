04

[40 s] Users and needs. A seafarer needs identity documents kept private and usable with no signal, so the app has no network permission and stores files in app-private storage. A crewing agent retypes the same five fields for every candidate, so the app extracts certificate name, issue date, port of issue, issuing authority and expiry date. A ship manager needs to find a document and its expiry quickly: library search, folders and an Ask screen that shows the source document. Everyone needs to turn a crooked photo into a clean page and to trust the result, so there is a crop editor, page flattening, editable text and an extractor that refuses to invent dates on non-certificates. I am open about the evidence: these personas come from the sourced facts and the certificate corpus I worked with, not from interviews. Expiry reminders are the most useful feature not yet built.
