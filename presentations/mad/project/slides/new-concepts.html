[45 s] The rubric asks for three or more new concepts. Here are six, each in a named file. One: three on-device ML runtimes, ML Kit, ONNX Runtime and TensorFlow Lite, where for handwriting I wrote the line cropping, tensor packing and CTC decoding myself. Two: a MiniLM question-answering model that I fine-tuned on certificate text and quantised to int8 at 32.3 MiB, with a WordPiece tokenizer written in Kotlin; it gets 15 of 26 fields on the human-checked gold set against 4 of 26 for my first prototype. Three: an OpenCV native pipeline. Four: hybrid extraction where rules come first and the model only answers with evidence. Five: coroutines with explicit dispatchers and cleanup of native resources. Six: the Activity Result API with a FileProvider and manifest rules that strip network permissions.
