[25 s] The solution has four moves. Capture: camera or gallery, then crop, flatten and clean the page. Read: ML Kit for printed text and PP-OCRv5 for handwriting. Extract: five certificate fields, using rules first, then the fine-tuned MiniLM, then MobileBERT as a fallback. Keep and ask: documents are saved in the app's private storage, searchable, and questions are answered offline with the source document shown. There is no account, no server and no analytics.
