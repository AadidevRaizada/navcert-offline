[45 s] The data flow, left to right. Capture from the camera or gallery. Optional crop in a second activity. Process with OpenCV on a background dispatcher: quality checks, page detection, perspective warp and enhancement. OCR has two lanes, ML Kit for print and PP-OCRv5 for handwriting. Extraction runs rules, then MiniLM, then MobileBERT. The user reviews and edits, the document is stored as a JSON file plus a JPEG preview, and the Ask screen retrieves chunks and runs MobileBERT. The dashed red frame is the key architectural decision: the INTERNET permission is removed, so none of this can leave the phone. Structurally it is one main activity hosting a Compose app with a navigation drawer, plus the crop activity. File work runs on Dispatchers.IO, vision and ML on Dispatchers.Default.
