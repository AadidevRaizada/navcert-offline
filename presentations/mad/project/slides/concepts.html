AADIDEV RAIZADA · N152 · MOBILE APPLICATION DEVELOPMENT · NMIMS MPSTME

09

[55 s] The rubric asks for three new concepts; here are twelve, each in a named file. Three on-device ML runtimes: ML Kit for printed text, ONNX Runtime running PP-OCRv5 for handwriting, where I wrote the line cropping, tensor packing and CTC decoding myself, and TensorFlow Lite running MobileBERT. I fine-tuned a MiniLM question-answering model on certificate text in Python, quantised it to int8 at 32.3 MiB, and wrote a WordPiece tokenizer in Kotlin to feed it. On the human-checked gold set it got 15 of 26 fields, against 4 of 26 for my first prototype. On the Android side: OpenCV native processing in yellow, a small retrieval engine, coroutines with the right dispatchers, an adaptive Material 3 drawer, the Activity Result API with FileProvider, and a cropper hosted in Compose.
