05

[45 s] The tools, with versions from the Gradle files, and why each was chosen. Kotlin and Jetpack Compose with Material 3 give a declarative UI, targeting SDK 36 with a minimum of 24. OpenCV 4.13 does the geometry: finding the page, warping it flat and enhancing it. ML Kit 16.0.1 reads printed text with a bundled model. ONNX Runtime 1.24.1 runs two models: PP-OCRv5 for handwriting and my fine-tuned MiniLM for certificate fields. TensorFlow Lite Task Text runs MobileBERT for document questions. Coil shows thumbnails and an image cropper library powers the crop editor. The choice of every tool follows from one constraint: no network, so every model ships inside the app.
