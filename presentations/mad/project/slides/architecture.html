05

[60 s] Architecturally it is one main activity hosting a Compose app, plus a crop activity reached through an explicit intent. Navigation is a Material 3 drawer with four destinations, and the scan flow is a three-step state machine: capture, preview, result. The camera uses the TakePicture contract with a FileProvider URI, so I need no camera permission. The bitmap is decoded on the IO dispatcher, OpenCV runs on the Default dispatcher, then ML Kit reads printed text; in handwriting mode each ML Kit line is re-read by PP-OCRv5 on ONNX Runtime. The extractor tries rules first, then my fine-tuned MiniLM, then MobileBERT. The user reviews and saves; each document is a JSON file plus a JPEG preview in app-private storage. The Ask screen chunks and ranks saved documents and runs MobileBERT on the best chunks. Every stage runs on the phone, inside the red frame: no network permission.
