[45 s] The result screen is a document editor, not a bare text box: line breaks are preserved, you can highlight phrases, add review notes and bookmark. Above it is the certificate summary with five fields. The extractor is hybrid: regular-expression rules handle labelled fields like 'issued at … on …' or 'valid until'. Only when a field is missing and the page shows evidence for it does it ask my fine-tuned MiniLM model, and only then MobileBERT. If the text is not a certificate at all, it asks no model, so it does not invent dates. Look at the Port row in this run: it shows the authority line, not the port. OCR and extraction can be wrong, which is why every field and every word stays editable.
