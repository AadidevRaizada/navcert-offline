[40 s] This is the real app. Saved documents appear in the library with thumbnails loaded by Coil, a search box, and folders, so an agent can keep one folder per crew member or per vessel. The Ask screen takes a plain question, splits the saved documents into overlapping chunks, ranks them with TF-IDF weighting where title words count three times, and runs MobileBERT on the top four chunks. The answer, highlighted on the right, comes back with the document it came from, so you can open the source and check it. It extracts a span from your text, it does not generate, so it cannot invent a date.
