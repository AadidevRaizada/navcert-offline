[35 s] I split testing in two. Pure Kotlin logic, which is where the bugs hide, is covered by JUnit tests that run without a device: extraction rules, port-of-issue labels, the extractor refusing to ask a model on non-certificates, rejecting truncated dates, the tokenizer, retrieval and OCR digit correction. That is 38 JVM unit tests with zero failures, including 18 on the Pipeline Lab image operations; the extractor now has ten tests and the OCR corrector six after the final fixes. Model quality is measured in Python against a human-checked gold set: 15 of 26 fields for the int8 model. The whole app was installed and run on an OPPO phone with Android 15. What I have not measured yet is end-to-end accuracy on photographed certificates, and I have not written instrumented UI tests; those are the next evaluation.
